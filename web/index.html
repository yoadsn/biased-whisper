Phase 4 — parallel teacher → LoRA

Independent training path; no Phase 2N or 3 required. Independent frozen teachers prepare a reusable target cache, then DDP trains the adapter without digit suppression. Natural cardinal and no-number examples can preserve existing behavior.

Training configuration

Parallel defaults: 8 GPUs, global batch 8 (one clip per GPU per update). On 4 GPUs the same batch uses accumulation 2. Decoder layers by default; encoder_top_layers optionally adds only the final encoder layers. cohort_run empty = latest established setup_scale split. Epochs must be 1–3. Disable parallel for the original one-GPU online path.

Completed compatible teacher targets are reused automatically. resume_run resumes an inactive parallel run's latest optimizer/adapter/RNG checkpoint; world size, accepted data and training settings must match. An old single-GPU run cannot be resumed as DDP; its files are preserved.

Phase 2N — component-level style units

Current discovery path. For each verified decision point, gradient × activation attributes the digit-vs-cardinal span to MLP neurons, attention heads and residual directions. Significance gates the units; effect size ranks them. Selected units become coherent output-gain edits for Phase 3.
